40 JavaFX Project Templates

These are intentionally barebones templates intended to be expanded when the exact project instructions are available.

Each file is standalone and contains:
- JavaFX Application
- Basic input fields
- Main action button
- Clear button
- ListView for records
- Basic validation
- main() method

The templates do not use packages.

For JavaFX, configure the JavaFX SDK/module path in your IDE or build system.
